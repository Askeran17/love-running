# Love Running 🏃‍♀️🏃‍♂️

A responsive multi-page website created for a fictional running club. Developed as part of the Code Institute curriculum, this project demonstrates proficiency in front-end development and design best practices.

## 📌 Project Overview

Love Running is designed to engage users who are passionate about running and promote community activities. The site features:
- A clean and intuitive layout
- Informational content about the club
- A photo gallery
- Contact and signup forms

## 🛠️ Technologies Used

- **HTML5** – Semantic structure and accessibility
- **CSS3** – Styling and responsive design

## 🌐 Deployment

This project was developed using the Codeanywhere IDE and can be previewed in a browser environment or hosted on platforms like GitHub Pages.

## 🚀 Features

- Multi-page navigation
- Mobile-first responsive design
- Signup form using HTML/CSS
- Visual content optimized for performance

## 📚 Learning Outcomes

- Mastering HTML/CSS layouts
- Understanding UX principles
- Applying version control with Git
- Organizing code for maintainability
